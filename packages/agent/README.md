# @wzrdtech/agent

Agent prompts, budget guards, and helper utilities for authoring and running Zap recipes, plus the v5 Zap bridge that connects the Eve agent framework to the Zap runtime.

```bash
npm install @wzrdtech/agent
```

Exports reusable agent instructions and budget guards for legacy 0.3.1 recipe agents, and the `zap-bridge` used by Studio and Eve-based hosts to drive v5 agents-as-code deployments and sessions.

For writing v5 agents, see `@wzrdtech/zap-agent` (agents as code) and the `zap agent` CLI commands.

Docs: https://zap.wzrd.tech · repo: https://github.com/gratitude5dee/Zap
