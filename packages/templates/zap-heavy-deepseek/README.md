# zap-heavy-deepseek

Overlay of `zap-heavy` (no named snapshot while dsh is an RC) that installs
`@deepseek-ai/dsh` at the pinned RC and drives it headless over `cli-exec`.
The manifest lives at `packages/runtime/src/harness/deepseek.ts`.

See `docs/templates/zap-heavy-deepseek.md` and `docs/harnesses/deepseek.md`.
