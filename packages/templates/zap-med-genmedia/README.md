# zap-med-genmedia

Alias of `zap-med` (no named snapshot of its own) that pins generative-media
defaults — fal for images, GMI for video, Replicate for speech — and enables
the `stitch`, `overlay`, and `gen-media-post` ffmpeg presets. Created through
`POST /boxes {from: "zap-med", setupScript}`.

See `docs/templates/zap-med-genmedia.md`.
